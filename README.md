# Attendance-Midterm

Expo SDK 57 mobile attendance application with Supabase authentication, role-based profiles, cloud events, QR generation, QR scanning, and attendance history.

## Setup

1. Copy `.env.example` to `.env` and add the Supabase project URL and anon key.
2. Run `supabase/schema.sql` in the Supabase SQL editor.
3. Run `npm install`.
4. Run `npm run start`.

Expo Go 57 requires the Expo CLI and Expo Go app to be signed in to the same Expo account on physical devices.
